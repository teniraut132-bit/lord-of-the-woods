# Хозяин леса — публичная веб-версия

Статическая браузерная версия системы покровительства Хозяина леса с картой проекта и отдельным военным советником.

## Публикация через GitHub Pages

1. Создайте **новый публичный репозиторий** с именем `lord-of-the-woods` в своём GitHub-аккаунте. Не используйте репозиторий `MedievalBattlefieldEditor`: это отдельный проект.
2. Загрузите в корень репозитория все файлы и папки из этого архива. В корне должны лежать `index.html`, `app.js`, `military-advisor.js`, `styles.css`, `extensions.css`, `assets/`, `sw.js`, `manifest.webmanifest` и папка `.github/`.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment → Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions**. Workflow `Deploy website to GitHub Pages` запустится после загрузки файлов. При необходимости нажмите **Run workflow**.
6. После успешной публикации сайт будет доступен по адресу:
   `https://teniraut132-bit.github.io/lord-of-the-woods/`

При каждом последующем push в ветку `main` сайт будет публиковаться автоматически.

## Что важно знать до публикации

- GitHub Pages публикует статический сайт. Это делает интерфейс доступным по общей ссылке, но **не создаёт общую базу данных**.
- В текущей версии государства, благосклонность, Клирика, контракты, друиды и военный советник сохраняются в `localStorage` браузера. Разные игроки пока будут видеть разные локальные наборы данных на своих устройствах.
- Для общей синхронизации, учётных записей, ролей игроков/вармастера и одновременного редактирования потребуется отдельный backend и облачная база данных (например, Supabase) с правилами доступа.
- Не помещайте в публичный репозиторий пароли, API-ключи, личные данные игроков или секреты кампании. Сайт GitHub Pages является публичным. API-ключ ИИ, если используется, вводится пользователем в интерфейсе и не должен быть зашит в исходники.
- Интерактивная карта проекта подключена как внешний iframe и остаётся отдельным сайтом: `https://serbakovboris56-cyber.github.io/LustDAY/`.

## Локальный запуск

Для локальной проверки в Windows можно распаковать проект и запустить `start_server.bat`. Откройте указанный им адрес в браузере.

## Основные разделы

- Обзор и обзор покровительства.
- Карта мира (внешний интерактивный сайт «Хроника государств»).
- Военный советник 2.6.
- Государства и регионы.
- Молитвы, подношения и благословения.
- Контракты.
- Друиды и посвящения.
- Военное покровительство.
- Журнал действий и справочник правил.
