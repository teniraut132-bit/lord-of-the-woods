# Хозяин леса — обновление 3.4

В этой сборке галерея рас использует изображения, присланные владельцем проекта. Внешний Excel-реестр государств и панель выбора из него удалены.

## Каталог рас

В справочник добавлены 18 народов: Нежить, Аренцы, Вампиры, Рун, Шаньди, Некомата, Гобы, Валесийцы, Грандийцы, Инверсы, Мазуры, Скавены, Тёмные орки, Ксатры, Тавуры, Тангуры, Бругачи и Друкхари. Для Ксатров повторно используется изображение Инверсов, как было указано в задании.

Все изображения находятся в `assets/races/`. Старые автоматически подобранные/сгенерированные портреты рас удалены из каталога и кэша Service Worker.

## Реестр государств

Внешний реестр и импорт списка государств удалены. Основная летопись государств приложения сохранена: она нужна для отдельного учёта благосклонности Владыки, Клирики, молитв, контрактов, регионов и благословений. В военном советнике страна для стороны указывается вручную.

## Публикация

Загружайте содержимое архива в корень репозитория GitHub Pages, заменяя файлы. Service Worker получил новый ключ кэша `lord-of-the-woods-v10-admin-prayers-battle-audit-34`, чтобы браузер удалил прежние портреты из старого кэша.


## Версия 3.4 — обращения, молитвы и аудит боёв

- Добавлен защищённый режим администратора на Supabase Auth с RLS. Вход использует email/пароль Supabase; секреты администратора и service_role key в клиент не помещаются.
- Игровые действия, молитвы, заявки, выбор тактик, изменение параметров армий и сражения отправляются в общую таблицу активности, если backend настроен.
- Администратор может ответить игроку и назначить статус; игрок видит ответ в блоке «Ответы Владыки».
- В молитвы добавлены гражданские эффекты: единство, годовой доход, пища региона, лояльность крестьян и запрос необычного месторождения за 5 Клирики.
- Каталог контрактов расширен; строительство священной рощи не является общим условием. Вознаграждение благосклонности теперь сохраняется в записи договора.
- Военный советник включает 10 автоматических тестов всех 71 тактик: каждую тактику можно выполнить через полный расчёт боя без профильного состава; отдельно проверены боевой дух «Боевых знамён», осадный урон, Клирика, расовые бонусы и скавенское снабжение.

### Настройка общей базы
См. `SUPABASE_SETUP_RU.md` и `supabase/schema.sql`. Пока URL/anon key не заполнены и схема не создана, приложение остаётся в локальном режиме, а межпользовательский админ-журнал недоступен. Общий журнал получает только новые события после подключения; старые локальные записи автоматически не переносятся. Полные игровые сохранения разных игроков не синхронизируются.
