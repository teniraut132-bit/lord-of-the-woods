# Хозяин леса — публичная веб-версия

Браузерное приложение для учёта государств, благосклонности Владыки, Клирики, благословений, контрактов, друидов и военных кампаний.

## Обновление 3.2

- Военный советник получил 71 тактика в шести группах (включая ночные, засадные, фланговые, обманные и оборонительные варианты). Все тактики выбираются независимо от численности или наличия конкретных родов войск. Профильные подразделения получают дополнительные эффекты только если они есть в составе.
- Снабжение дурманом и поле «Ремесло» доступны только армиям с расой Скавены (или ещё не определённой расой государства Хирд-Скерри). У других рас эти значения обнуляются.
- Из формулы содержания исключены «Арсенал», «Цитадель» и источники железа. Сохраняется отдельный параметр укреплений как прочность стен в конкретном сражении; это не скидка на содержание.
- Исправлена миграция благосклонности в старых сохранениях. Отсутствующее значение получает начальные 10/100. Поступки и исполнение/нарушение контрактов заносят фактическое изменение в журнал; добавлена корректировка вармастера.
- Внешний реестр можно полностью очистить. Связи армий с реестром снимаются, но состав уже созданных армий сохраняется.
- Excel-импорт читает несколько листов, числовые значения, строки и столбцы статистики, отдельные карточки государств, а не только текстовое название. Распознаваемые поля становятся структурированными данными; остальные показатели сохраняются в дополнительных статистических полях.
- Отдельная вкладка «Военное покровительство» и интерфейс «ИИ-Штаб» не используются. Каталог военных благословений Владыки сохранён в разделе «Молитвы и дары».

Каждая карточка содержит собственный файл иллюстрации, внешность, срок жизни и физические особенности.
- Карточка расы автоматически меняется вместе с выбранной расой государства. Ранее сохранённые армии и отряды остаются совместимыми.
- Общий реестр показывает все импортированные государства, не только почитающие Владыку. У каждой строки есть действие «Добавить в летопись» / «Выбрать»; локальная летопись связывается с импортированной записью по её ID.
- Форма нового государства выбирает запись из общего реестра вместо свободного ввода названия. При выборе автоматически подставляются название, религия, раса, Клирика и священники; население и феодалы остаются связаны с исходной статистикой.

- Добавлены алиасы для названий рас из анкет: Аренские лисы, Vampire Affectuum, Та-Рун, Шаньди де Суньмин, Грандины, Барзум-уруки, Ксатры/сатиры, Багбиры/Бругачи и другие.

Иллюстрации рас расположены в `assets/races/` и предварительно кэшируются сервис-воркером. Версия кэша увеличена, чтобы браузер не продолжал использовать старые карточки.

## Публикация через GitHub Pages

1. Загрузите в корень репозитория все файлы и папки из этого архива, заменив одноимённые старые файлы.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. После Commit в ветку `main` откройте вкладку **Actions** и дождитесь успешного запуска `Deploy website to GitHub Pages`.
4. Для этого репозитория адрес сайта: `https://teniraut132-bit.github.io/lord-of-the-woods/`.

При каждом последующем push в ветку `main` сайт публикуется автоматически.

## Импорт статистики государств

В разделе **Государства** нажмите **Импорт Excel**. Поддерживаются `.xlsx`, `.xls`, `.csv` и `.json`.

Поддерживаемые макеты книги:

1. Таблица: одно государство на строку, показатели в столбцах (например, `Государство`, `Религия`, `Раса`, `Население`, `Феодалы`, `Крестьяне`, `Священники`).
2. Развёрнутая таблица: государства в названиях столбцов, показатели в строках.
3. Карточка государства: подписи показателей в первом столбце, значения рядом; допускается отдельный лист на каждое государство.
4. Несколько листов одного формата — записи объединяются по названию государства.

Известные показатели, такие как население, феодалы, лояльность феодалов, сословия, раса, религия, священники, Клирика, армия и годовой призыв, распознаются для расчётов. Остальные значения сохраняются в `stats` и отображаются в панели связанного государства в военном советнике. Если в книге нет феодалов или готовых значений годового призыва, советник использует базовое правило: 10 феодалов дают 5 специалистов и 20 сброда за год.

В разделе «Государства» показывается полный импортированный реестр. При выборе любой записи, независимо от религии, она добавляется в личную летопись и становится доступна в общем селекторе активных государств и военном советнике.

**Важно:** настоящий заполненный исходный Excel-пример статистики государства должен быть загружен отдельно, чтобы проверить соответствие нестандартных названий столбцов именно ему. Импортёр поддерживает общие распространённые структуры, но не может гарантировать автоматическую классификацию любого произвольного листа без просмотра образца.

## Сохранение и совместимость

- Данные хранятся в `localStorage` конкретного браузера и профиля. Общей облачной базы между игроками пока нет.
- Формат существующих сохранений и экспорт кампании сохранены. При первом открытии обновлённая версия сохраняет прежние записи благосклонности и армии, добавляет связь с импортированным реестром и подхватывает новые карточки рас.
- Перед обновлением рекомендуется экспортировать резервную копию приложения и кампании.
- Встроенная карта подключается как внешний iframe: `https://serbakovboris56-cyber.github.io/LustDAY/`.

## Локальный запуск

В Windows распакуйте проект и запустите `start_server.bat`, затем откройте локальный адрес, указанный в окне.
