# Хозяин леса — публичная веб-версия

Статическое браузерное приложение с системой покровительства Владыки, внешней интерактивной картой и самостоятельным военным советником.

## GitHub Pages
В репозитории настроен workflow `.github/workflows/deploy-pages.yml`. В Settings → Pages выберите GitHub Actions. При каждом push в main сайт публикуется автоматически.

Адрес: https://teniraut132-bit.github.io/lord-of-the-woods/

## Важно
Текущие игровые данные сохраняются локально в браузере через localStorage. Публичный сайт доступен всем, но совместной облачной базы, авторизации и разграничения ролей пока нет. Не храните секреты и приватные данные в публичном репозитории.
