# Обновление 3.3.1 — исправление отображения иллюстраций

- В карточках расы военного советника изменён режим `object-fit: cover` на `object-fit: contain`: иллюстрация больше не обрезается по краям.
- Ширина области иллюстрации немного уменьшена (до 220 px), высота — до 142 px; пропорции исходника сохраняются.
- В энциклопедии рас изображения также приведены к более компактному блоку с полным отображением.
- Исходные WebP-файлы не пережимались и не изменялись; исправлено только CSS-отображение.
- Обновлена версия Service Worker cache, чтобы браузеры забрали новые стили после публикации.
