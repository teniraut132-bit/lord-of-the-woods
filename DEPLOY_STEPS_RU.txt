ОБНОВЛЕНИЕ «ХОЗЯИНА ЛЕСА» ДО ВЕРСИИ 3.4

1. Перед обновлением экспортируйте резервную копию данных приложения через кнопку ⇩ в верхней панели.
2. Распакуйте архив целиком.
3. Откройте репозиторий GitHub и выберите Add file → Upload files.
4. Загрузите всё содержимое распакованной папки в корень репозитория, заменив одноимённые файлы. Не загружайте ZIP как один файл.
5. Нажмите Commit changes в ветку main.
6. Откройте Actions и дождитесь успешного завершения публикации.
7. Откройте сайт и при необходимости выполните жёсткое обновление страницы (Ctrl+F5).

В версии 3.4 изменён ключ Service Worker: старый кэш должен быть очищен автоматически, а изображения рас загружены заново.

ВНИМАНИЕ: не удаляйте и не перемещайте папку assets/races. В ней находятся пользовательские изображения 18 рас (Ксатры используют арт Инверсов по отдельному указанию).

Внешний Excel-реестр государств и панель его выбора удалены. Основная летопись государств приложения сохранена для управления благосклонностью, Клирикой, молитвами и контрактами.


Для межпользовательского режима требуется отдельно настроить Supabase по файлу SUPABASE_SETUP_RU.md и выполнить supabase/schema.sql.
