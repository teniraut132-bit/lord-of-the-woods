ОБНОВЛЕНИЕ «ХОЗЯИНА ЛЕСА» ДО ВЕРСИИ 2.7

Репозиторий уже создан: https://github.com/teniraut132-bit/lord-of-the-woods

1. Распакуйте архив обновления.
2. Откройте репозиторий https://github.com/teniraut132-bit/lord-of-the-woods
3. Нажмите Add file -> Upload files.
4. Перетащите в окно всё содержимое папки проекта из архива, включая assets и .github. Не загружайте ZIP как один файл и не вкладывайте файлы в дополнительную папку.
5. Подтвердите замену одноимённых файлов и создайте commit в ветку main.
6. GitHub Actions автоматически запустит публикацию. Дождитесь зелёной галочки в Actions.
7. Сайт: https://teniraut132-bit.github.io/lord-of-the-woods/

Если это новый пустой репозиторий, предварительно создайте его с именем lord-of-the-woods, а в Settings -> Pages выберите Source: GitHub Actions.

ИМПОРТ EXCEL
В приложении откройте «Государства» -> «Импорт Excel». Импортируется первый подходящий лист с заголовками «Государство»/«Страна» и «Феодалы». Дополнительные колонки: «Религия», «Поклоняется Владыке», «Раса», «Население», «Лояльность феодалов». Военный советник получает весь список, а в разделе государств показываются только почитающие Владыку.

ВАЖНО
- Все данные по-прежнему сохраняются отдельно в браузере каждого участника (localStorage). Общей базы и синхронизации между игроками нет.
- API-ключи, пароли, личные данные и секреты не добавляйте в публичный репозиторий.
- Расчёт боевых тактик абстрактный: приложение не моделирует перемещение на карте, фланговые маршруты, местность и выбор целей.
