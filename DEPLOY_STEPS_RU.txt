ОБНОВЛЕНИЕ «ХОЗЯИНА ЛЕСА» ДО ВЕРСИИ 3.0

1. Перед обновлением экспортируйте резервную копию приложения и военной кампании.
2. Распакуйте архив обновления.
3. Откройте репозиторий https://github.com/teniraut132-bit/lord-of-the-woods
4. Нажмите Add file → Upload files.
5. Загрузите ВСЁ содержимое распакованной папки в корень репозитория, заменив одноимённые файлы.
   Не загружайте ZIP-архив как один файл. В корне должны находиться index.html, app.js,
   military-advisor.js, styles.css, extensions.css, sw.js, manifest.webmanifest, assets/ и .github/.
6. Сделайте Commit changes в ветку main.
7. Откройте вкладку Actions и дождитесь зелёной галочки у workflow Deploy website to GitHub Pages.
8. Откройте сайт: https://teniraut132-bit.github.io/lord-of-the-woods/

После обновления service worker v5 должен очистить прежний кэш и загрузить файлы версии 3.0.
Если браузер продолжает показывать старую версию, выполните жёсткое обновление страницы (Ctrl+F5).
